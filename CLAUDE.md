# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a static personal website (claudioscheer.github.io) with no build system or package manager. All pages are plain HTML with inline styles, served directly by GitHub Pages.

## Adding a Blog Post

1. Create a Markdown file under `blog/<tag>/post-name.md`. The first line (a `# Heading`) becomes the post title; the directory name becomes the tag/category.
2. From the `blog/` directory, run the generation script to create the HTML wrapper and update the post index:
   ```bash
   cd blog && bash create-posts.sh
   ```
   This script reads each `.md` file, copies `template.html` with `##FILE_NAME##` replaced by the `.md` path, and regenerates `posts.json`.

## Adding Gallery Images

Place large images in `gallery/large/`, then from the `gallery/` directory run:
```bash
cd gallery && bash create-gallery.sh
```
This uses ImageMagick (`convert`) to generate 600px thumbnails into `gallery/thumb/` and regenerates `gallery.json`.

## Architecture

- **`index.html`** — Homepage; static HTML with Tailwind CSS (CDN) and Inter font.
- **`blog/`** — Blog section:
  - `index.html` loads `posts.json` via `js/blog.js` and renders post links grouped by tag.
  - `template.html` is the per-post shell; it fetches the `.md` file at runtime and renders it with [Showdown.js](https://github.com/showdownjs/showdown) (CDN).
  - `posts.json` is the generated index; **do not edit manually** — regenerate with `create-posts.sh`.
  - Markdown source lives alongside the generated HTML (e.g., `blog/ai/post.md` → `blog/ai/post.html`).
- **`gallery/`** — Photo gallery:
  - `index.html` loads `gallery.json` via `js/gallery.js`.
  - `gallery.json` is generated by `create-gallery.sh`; **do not edit manually**.
  - Thumbnails live in `gallery/thumb/`.
- **`css/`** — Unused legacy stylesheets (`air.css`, `retro.css`, `github.min.css`); current styling is inline in each HTML file.
- **`icons/`** — SVG social icons referenced in `index.html`.
- **`assets/`** — Static assets: `resume.pdf` and `pgp-key.txt`.

## Deployment

Pushing to `master` deploys automatically via GitHub Pages. No build step required.
